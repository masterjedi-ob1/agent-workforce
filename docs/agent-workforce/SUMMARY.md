# Agent Workforce Plan — Summary

**Read time: 60 seconds.**

The audit on 2026-08-27 showed the real problem: $120K of priced pipeline, all eight Tier 1 deals cold, no client touch in two days, and thirteen scheduled tasks that quietly died. The fix is not more agents. It is four agents wired to one funnel, each one handing work to the next stage, with Chris as the only seat that sends.

**The funnel:** touch → book → close → refill.

1. **Deal Reviver** drafts the follow-up email for every cold deal each morning, pulling real thread context from Gmail. Built first because it closes the biggest gap today.
2. **Pre-Call Briefer** writes a one-page brief for every external meeting in the next 48 hours so revived deals do not walk into cold calls.
3. **Signal** drafts one LinkedIn post three mornings a week from real work, with a publish checklist so drafts stop dying in a folder.
4. **Prospector** refills the top of the funnel every Monday with 10 to 15 scored names and openers, staged for approval, never sent.

**How it gets built:** Fable Foreman leads. It plans, routes, and reviews. Cheaper worker seats write and register each skill. A blind verifier checks that each task fires and the output meets spec. Six tickets, run in order, about three hours.

**What Chris does:** re-auth Stripe, confirm the pipeline MCP seat, say "go". Then approve and send drafts every morning.

**What we are not building yet:** CFO agent, CRM hygiene, handoff monitor, dashboard, distressed-business scan. Two weeks of funnel data first.

**Success in two weeks:** cold deals from 8 to 3 or fewer, at least ten touches drafted and six sent per week, two of three posts published, ten new prospects staged.
